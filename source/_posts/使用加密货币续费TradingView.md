这几天TradingView一年一度的黑色星期五促销活动支持加密货币支付，特来续期体验一下，同时这也是我首次使用加密货币进行替代法币交易。

我的方案续期一年的费用是$108，节省40%左右。

{% asset_img 1.png This is an example image %}

跳转到加密货币支付的方式进行支付，我选择了LTC，交易所提现费用低，转账手续费也低。

{% asset_img 2.png This is an example image %}

首先去交易所购买了1.4个LTC

{% asset_img 3.png This is an example image %}

然后提现到自己的onekey硬件钱包

{% asset_img 4.jpg This is an example image %}

这里我没有直接支付给TradingView，是想体验一下自己的安全支付流程。

3分钟到账，提现手续费忽略固定0.001LTC，手续费是加密货币的优势之一，你提几个亿也是这个手续费。

钱包到账！

{% asset_img 5.png This is an example image %}

然后个人钱包进行支付

输入支付地址，输入数量。

{% asset_img 6.jpg This is an example image %}

硬件钱包支付确认就行了。

{% asset_img 7.jpg This is an example image %}

然后TradingView显示支付完成了

{% asset_img 8.png This is an example image %}

就此支付完成，诚然这种支付方式进入日常支付系统还有很长路要走，相信未来这个领域不仅能存活下去，还能慢慢渗透人们的日常生活。
